# FP4_DotProd 文档入口

算术规格已合并到按硬件模块组织的 [blackwell_fp4_dot](../rtl_specs/dot/blackwell_fp4_dot.md)。该文档完整定义数值步骤、接口、寄存级、背压与验证要求。

共享格式与舍入规则见 [Dot数值规则](../rtl_specs/tensor_core/blackwell_tc_dot_array.md#numeric-routing)，64路集成见 [blackwell_tc_dot_array](../rtl_specs/tensor_core/blackwell_tc_dot_array.md)。本页只保留入口，不维护第二份算法或周期表。
