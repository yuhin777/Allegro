# FP4_DotProd documentation

The [blackwell_fp4_dot](../rtl_specs/dot/blackwell_fp4_dot.md) specification defines the arithmetic, interfaces, pipeline registers, backpressure, and verification requirements.

See [Dot arithmetic rules](../rtl_specs/tensor_core/blackwell_tc_dot_array.md#numeric-routing) for shared formats and rounding rules and [blackwell_tc_dot_array](../rtl_specs/tensor_core/blackwell_tc_dot_array.md) for 64-lane integration.
